# Author Platform — প্রজেক্ট ওভারভিউ

## প্রজেক্ট সম্পর্কে
একজন বাংলাদেশী লেখকের জন্য পার্সোনাল অথর প্ল্যাটফর্ম/পোর্টফোলিও ওয়েবসাইট। লেখক নিজে কন্টেন্ট ম্যানেজ করবেন (single-author system)। বই বিক্রি হবে না সরাসরি সাইট থেকে — বরং "Buy Now" বাটনে ক্লিক করলে Rokomari, Amazon বা অন্য কোনো প্ল্যাটফর্মে রিডাইরেক্ট হবে। কোনো পেমেন্ট গেটওয়ে/ট্রানজেকশন ইন্টিগ্রেশন নেই।

## টার্গেট ইউজার
- **লেখক (Author/Admin)** — কন্টেন্ট তৈরি ও ম্যানেজ করবেন
- **পাঠক (Reader/Visitor)** — শুধু পড়বেন, বই দেখবেন, বাইরের লিংকে গিয়ে কিনবেন

## মনিটাইজেশন
বর্তমানে ফ্রি প্ল্যাটফর্ম। ভবিষ্যতে বিজ্ঞাপনভিত্তিক মনিটাইজেশনের সম্ভাবনা রাখা হয়েছে (কোড স্ট্রাকচারে বাধা দেবে না এমনভাবে ডিজাইন)।

## টেক স্ট্যাক

| স্তর | টুল/টেকনোলজি |
|---|---|
| Backend Framework | Laravel 11 |
| Frontend Integration | Inertia.js |
| Frontend Framework | Vue 3 (Composition API) |
| CSS | Tailwind CSS |
| Rich Text Editor | TipTap (বা Quill.js) |
| Auth | Laravel Breeze/Fortify (কাস্টমাইজড, শুধু ১ জন ইউজার) |
| Admin Panel | কাস্টম কোড (কোনো থার্ড-পার্টি প্যাকেজ যেমন Filament/Nova ব্যবহার হবে না) |
| Media Handling | Spatie Media Library (ঐচ্ছিক — কভার ইমেজ/ফিচার্ড ইমেজের জন্য) |
| ভাষা সাপোর্ট | মাল্টি-ল্যাঙ্গুয়েজ — বাংলা ও ইংরেজি |
| ডাটাবেজ | MySQL |

## মূল ফিচার মডিউল
1. বই/পাবলিকেশন ম্যানেজমেন্ট (একাধিক বাহ্যিক কেনার লিংকসহ)
2. ব্লগ/আর্টিকেল সিস্টেম (rich text editor সহ)
3. স্ট্যাটিক পেজ ম্যানেজমেন্ট (About, Contact)
4. ইভেন্ট/অ্যাপিয়ারেন্স (ঐচ্ছিক — বইমেলা, লঞ্চ ইভেন্ট)
5. সাইট-ওয়াইড সেটিংস (সোশ্যাল লিংক, SEO মেটা)
6. কাস্টম অ্যাডমিন প্যানেল (`/admin`)
7. মাল্টি-ল্যাঙ্গুয়েজ সাপোর্ট (বাংলা/ইংরেজি টগল)

## পাবলিক সাইট পেজ স্ট্রাকচার
- Home — ফিচার্ড বই, সাম্প্রতিক পোস্ট
- Books (তালিকা + ফিল্টার বাই জনরা)
- Book Detail (কভার, বিবরণ, একাধিক Buy Now বাটন)
- Blog (তালিকা + সিঙ্গেল পোস্ট পেজ)
- About / লেখক পরিচিতি
- Contact

## SEO ও পারফরম্যান্স নোট
- Slug-based URL (`/books/book-title`, `/blog/post-slug`)
- Meta tags ম্যানুয়ালি হ্যান্ডল অথবা Inertia SSR সেটাপ
- বাংলা ফন্ট ইন্টিগ্রেশন (SolaimanLipi / Noto Sans Bengali)
- ইমেজ অপ্টিমাইজেশন (কভার ইমেজ কমপ্রেশন)
